# fastapi-crud

FastAPI CRUD service with Docker, Alembic migrations, and a structured production app layout.

## What this project shows
- REST API built with FastAPI
- Docker-based local setup
- Alembic database migrations
- Structured `app/` package layout

## Getting started
docker compose up --build

Then open the API docs at http://localhost:8000/docs (confirm the port in docker-compose.yml if different).

Python • FastAPI • Docker • Alembic • REST APIs
